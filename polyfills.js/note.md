1️⃣ What is a Polyfill?
Answer
A polyfill is a custom implementation of a built-in JavaScript method.

Array.prototype.myMap = function() { ... }

2️⃣ Why do we use Polyfills?

To support older browsers
To understand internal working of JS methods
To show deep JS knowledge in interviews


5️⃣ Tricky Interview Question
👉 What happens if array is empty in reduce?

If no initial value is provided → error
If initial value is provided → returns initial value

6️⃣ Real Interview Question
👉 Can you write your own map function?
Answer
Explain loop + callback + return array
(then write polyfill)
